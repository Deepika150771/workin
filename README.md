# Workin - Employer Commission & Payment Feature

A voice-first, verified labour marketplace connecting daily-wage workers with employers in Tamil Nadu.

## Features
- **100% Free for Workers**: Workers never pay anything and see zero commission UI.
- **Employer Commission Model**: Employers pay a small commission (8% of agreed wage) ONLY after job completion.
- **Dynamic Commission Preview**: Live calculation preview when posting jobs (`Wage` → `Commission 8%` → `Total`).
- **Two-Way Job Completion Confirmation**: Simple confirmation system between employer and worker.
- **Payment Summary & MVP Payment Collection**: Shows exact wage, commission breakdown, and a "Pay Now" MVP payment button.
- **"My Payments" Transaction History**: Employer dashboard for tracking past jobs, wages, and commission payments.
- **Admin Revenue Dashboard**: Platform-wide revenue and commission tracking.

## Getting Started

### Prerequisites
- Node.js (v18+)

### Installation
```bash
npm install
```

### Run Server
```bash
node server/index.js
```
Open [http://localhost:5000](http://localhost:5000) in your browser.

### Run Verification Tests
```bash
node server/test_step1.js
node server/test_step2_3.js
```
